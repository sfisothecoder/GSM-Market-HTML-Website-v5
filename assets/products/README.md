# Product image sources

Product photos are stored locally. See [sources.json](sources.json) for the original image URLs, source listings, and per-product match notes. Images retain their original colours and proportions.

Every listing now matches a specific, named product (no generic placeholder photos remain). The iPhone 13 listing is a certified pre-owned unit; its photo is the retailer's stock photo, so confirm battery health and cosmetic grade before buying. Other photos match the named product; colour, configuration and included accessories still need confirmation.

The original rights remain with the respective photographers, manufacturers and retailers. Downloading and attribution do not establish a reuse licence.
